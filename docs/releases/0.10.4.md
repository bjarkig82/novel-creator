# Novel Creator 0.10.4

**Published on PyPI on 2026-11-19**, compared with [0.10.3](0.10.3.md).
[PyPI distributions](https://pypi.org/project/novel-creator/0.10.4/#files)

When you describe a possible future alliance, a recap or handoff should keep
it a proposal. Even if you confirm the alliance will happen, a character's
current intentions remain open until you establish them. The guidance also
asks the agent to preserve who controls something a character needs, how that
dependency can hurt them, and any corrections you make. Understanding the
other party does not remove the danger.

In a voice continuation that includes earlier transcript text, the agent should
distinguish your current words from earlier speech and assistant paraphrases.
A recap or an unclear speaker supplies no approval to accept an idea or save a
draft. The notebook conversation guide and the legacy brainstorming and resume
guides carry these rules. Existing save rules, book formats and skills are
unchanged. [Issue #11](https://github.com/bjarkig82/novel-creator/issues/11) ·
[Issue #12](https://github.com/bjarkig82/novel-creator/issues/12)

## Install and update

Install from an external Python 3.11+ environment with
Git 2.39+ available.

```text
python -m pip install --upgrade novel-creator==0.10.4
```

New legacy novels and new notebooks receive the guidance at normal initialization.
Existing legacy novels need a reviewed framework update targeting `0.10.4`,
which creates one framework commit. Existing 0.10.3 notebooks need a reviewed
`retro issue setup` application, which updates the pinned conversation guide
without a story save or checkpoint. Plugin users also need the matching enabled
plugin. Reread the book's root instructions, actual skills and linked workflows
in the host. [Commands for all four project cases](../upgrading-projects.md#story-status-in-summaries-and-handoffs-in-0104)
