# Novel Creator 0.10.7

**Unpublished release candidate**, compared with [0.10.6](0.10.6.md).

## Changes since 0.10.6

- `debug status --novel BOOK --debug-session ID` can find a session in a notebook
  that still has legacy-format markers. If the same ID exists in both formats,
  specify `--format novel-notebook` or `--format legacy`. Without a session ID,
  a mixed-format project still lists legacy sessions by default. Specify
  `--format novel-notebook` to list the notebook sessions. This selector is
  available on `debug status`. [Debug commands](../functionality.md#optional-session-debugging)
- In both formats, a verified GitHub connector issue receipt returns the issue
  URL, approved preview digest and upload state in a compact confirmation. The
  full saved record, including duplicate-check evidence, is available through
  `retro issue status --novel BOOK --run RUN --json`. [Retrospective workflow](../../workflows/retrospective.md#host-github-connector-fallback)
- `retro issue status --novel BOOK --run RUN --finding FINDING --json` returns
  one finding, including a no-action finding. A finding absent from the selected
  run gives a finding-not-found error. Omitting `--finding` returns the entire
  selected run.
- In format-1 notebooks, prepared recaps, permitted note saves and later
  summaries or handoffs keep a character's inference attributed to that
  character and leave deliberately unspecified details open. This also applies
  when an earlier assistant recap filled in the missing detail.
  [Notebook conversation guide](../../notebook/workflows/conversation.md#story-status-in-replies-recaps-and-handoffs)
- Format-1 notebook guidance separates a verified file save from a blocked Git
  checkpoint. After reporting a Git index permission denial, the assistant
  continues authorized file saves and records the exact paths with history
  pending in the active conversation. Git writes can resume through an approved
  access route, a material change in access, or a writer-requested retry within
  host permissions. A retry requires fresh Git inspection and protects unrelated
  staged changes. [Deferred notebook checkpoints](../functionality.md#deferred-notebook-checkpoints)

## Install or upgrade

Run this command **after 0.10.7 is published**, in a Python environment
outside the novel. Use a supplied 0.10.7 candidate artifact for prepublication
validation. Published installation remains on [0.10.6](0.10.6.md) in the meantime.

```text
python -m pip install --upgrade novel-creator==0.10.7
```

New legacy novels and format-1 notebooks receive the guidance for their format
at setup. Existing legacy novels use the reviewed framework update. Existing
format-1 notebooks refresh their pinned conversation and retrospective guides
through reviewed issue setup. Plugin notebooks also need the matching enabled
plugin. Reopen the project and reload its instructions and skills in the host.
The recap and checkpoint changes apply to format-1 notebooks. [Complete project upgrade steps](../upgrading-projects.md#upgrade-to-0107)
