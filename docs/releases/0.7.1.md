## Fixes from 0.7.0

In 0.7.0, Clarify, Analyze and Help were installed only when creating a new
Markdown notebook. Upgrading the package left existing projects without those
entries, and legacy novels did not receive them even through their supported
updater. Version 0.7.1 supplies legacy-specific skills and an explicit additive
update command for existing notebooks.

- Legacy novels receive `$novel-clarify`, `$novel-analyze` and `$novel-help` through
  their supported reviewed framework update. Clarification preserves legacy
  authority and exact-exchange persistence. Analysis and help explicitly bypass
  capture, session changes and journal writes for a read-only pass.
- Existing notebooks can preview and apply an additive retrofit of the three
  skills, linked guidance and instruction routing. Story content and custom
  instructions are preserved; differing customized resources block replacement.
  The retrofit does not stage, commit or push and does not replace all historical
  notebook resources. New notebooks retain these skills during initialization.
- Release instructions require an applicability check and tested upgrade paths
  for existing projects, complete user upgrade steps, and an annotated version
  tag pointing to the qualified source commit.

## Installation and existing novels

Install the exact published patch in the configured environment:

```text
python -m pip install --upgrade novel-creator==0.7.1
```

Then follow [the project upgrade guide](../upgrading-projects.md). For a legacy
novel, preview and apply 0.7.1 using the supported external updater. For a notebook,
preview with `novel-creator notebook update --path BOOK --json`, then apply the
returned preview and HEAD explicitly. Reload project instructions and skill
discovery in Codex after verified completion. A package upgrade alone still does
not mutate existing projects. Never initialize over a novel to add the skills.

Story formats, stable identities, manuscripts and record schemas are not migrated.
Legacy update recovery and ownership safeguards remain in force. Notebook updates
can leave partial additions on interruption; preserve them and preview again.
