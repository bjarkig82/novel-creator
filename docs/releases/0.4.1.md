# Novel Creator 0.4.1

**Status: qualified but unpublished candidate.** Version 0.4.1 passed automated
Windows/Linux release qualification; PyPI publication remains pending. This patch release
compares with the verified published [0.4.0](0.4.0.md), built from source
`abaca5ff90ce1adc90274e5515209a87bf6c58f7`. No publication date or availability
is claimed.

## Agent-led setup handoff

New project instructions direct ongoing work through Novel Creator after setup.
Legacy initialization returns runtime and project handoff paths in both shorthand
and brief-file modes. Agents must read the destination's instructions and saved
context before creative replies, and check available runtime evidence before
asking the writer to locate Python. Notebook initialization also installs clearer
handoff guidance without adding a per-turn Python requirement.

The host must have access to the new folder. Setup does not automatically switch
the active project, and a parent workspace does not guarantee discovery of nested
instructions. See [agent-led setup](../../workflows/start-here.md#ask-your-agent-to-set-up-a-story).

## Explicit legacy realtime input capture

Legacy input capture accepts `--source realtime_delegation` when the exact,
complete current public wrapper is directly available. A strict direct JSON
container retains that raw wrapper and its separate `transcript_delta`, which
may mix earlier user and assistant speech. Only the exact current `<input>`
becomes the saved user message. Earlier transcript context cannot authorize a
current instruction, acceptance or retrospective opt-in.

The capture preserves Unicode, whitespace, LF/CRLF, ordinary angle text and
ampersands. Truncated, malformed, nested, ambiguous or mixed wrappers fail;
structural delimiter text inside fields is unsupported. Saved provenance is
validated against the exact current message and original source. Realtime capture
is labeled separately from native user input and evaluation delegation; it makes
no native-input or novice-evidence claim. Never manufacture native messages,
reconstruct an unavailable wrapper or invent host IDs.

Local capture/save works independently of retrospective participation and does
not require a native chat-reading tool or stable host identity. Optional current
thread/turn IDs must be a genuine host-supplied pair. Retrospectives still require
explicit opt-in, a confirmed completion save and genuine stable identity for the
initiating task. The initiating turn may differ from the completion turn; later
identity availability cannot prove earlier identity. Missing initiating identity
means skip the retrospective and disclose the limit. See the
[entry workflow](../../workflows/entry.md) and
[retrospective workflow](../../workflows/retrospective.md).

## Stronger synthetic transport regression checks

Retrospective tests now check uppercase and lowercase proxy settings, certificate
settings, absent settings, excluded repository/configuration overrides and
unrelated secrets, and noninteractive isolated Git configuration in synthetic
child processes. They make no GitHub requests. Proxy/certificate preservation was
already implemented by `a535b03` and included in published 0.4.0; 0.4.1 does not
introduce that runtime network fix. See [network settings](../development.md#retrospective-network-settings).

## Installation and compatibility

**Usable only after 0.4.1 is published:**

```text
python -m pip install --upgrade novel-creator==0.4.1
```

Until then, 0.4.0 remains the verified published release. Python 3.11+, Git 2.39+
and an existing Git identity remain required. No record migration or breaking
format change is introduced.

Installing the package leaves existing novels and their pinned resources
unchanged. To acquire updated legacy resources after publication, use the
[explicit supported existing-book update](../../workflows/getting-started.md#updating-an-existing-book)
and reload the project's instructions and skills after success. Existing
notebooks are not automatically updated or migrated; new notebook guidance is
installed only when initializing a new notebook. These legacy capture rules do
not add transcript archival or a save-before-display gate to notebook writing.
