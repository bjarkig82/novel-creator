# Novel Creator 0.9.0

Status: **verified published on PyPI, 2026-11-12**, compared with
[0.8.0](0.8.0.md). Full Linux and full Windows qualification, both public
installation checks and an independent clean public installation passed. Public
wheel/source hashes match the qualified candidate and the annotated source tag
is verified. GitHub release and plugin/marketplace ZIP completion remain pending.

Character profile development adds one focused batch of proposed prose: a short
summary and 2–3 numbered connected additions, with an optional focus. Drafts and
revisions stay entirely in chat until explicit approval to save current or
selected additions. Praise, discussion and selection alone do not save. Accepted
facts, owning notes, stable IDs, history and unresolved questions remain protected;
ordinary Character and Clarify retain their question-led behavior. No new role,
provider, schema or CLI writing command is introduced.

New English/Icelandic format-1 notebooks include the feature for Codex, Claude
Code or both, with project skills or the enabled plugin. Project skills use the
host's local directory and syntax. Plugin books use the namespaced enabled entry
and their pinned workflow snapshot, without duplicate project skills. The plugin
contains fifteen writing skills plus setup.

| Format and age | Availability and follow-up |
| --- | --- |
| New legacy novels | No new character-development method; existing legacy behavior preserved. |
| Existing legacy novels | No new method or conversion; existing reviewed legacy updater remains available. |
| New notebooks | Feature installed during setup for all supported hosts, skill sources and languages. |
| Existing notebooks | Explicit update required: default unmarked Codex/project uses reviewed preview/apply; all supported host/plugin layouts have a tested manual procedure, also available as a default-layout alternative. |

Install or upgrade the exact published package in your configured environment:

```text
python -m pip install --upgrade novel-creator==0.9.0
```

Package/plugin upgrades leave existing book snapshots unchanged. Follow the
[upgrade guide](../upgrading-projects.md#090-character-development)
and [manual procedure](../character-development.md#manually-install-into-an-existing-format-1-notebook).
The default updater adds the feature and protected approval section, refreshes
only the provenance-verified public Help snapshot and preserves custom resources.
The manual procedure copies the rendered feature workflow and needed local skills,
merges bounded host root sections, and retains the older Help catalog. Conflicts
stop before writes; reconcile customized content without replacing broad guidance.
Both paths preserve story bytes, custom instructions, staging and history, and
perform no automatic checkpoint/push. Interrupted writes require inspecting and
reconciling actual partial work before retrying. No marketplace adoption is added.

After verified installation, reread the actual root guidance, entry and workflow
in the selected host, and use its supported reload/reopen controls if available.
Plugin users must upgrade/enable the plugin too. Native discovery, active-chat
reload and subjective English/Icelandic literary quality remain separate checks;
unsaved chat drafts have no guaranteed recovery. See the
[feature evaluation](../../tests/evaluations/character-development.md) and
[release evidence](../../tests/evaluations/release-0.9.0.md).
