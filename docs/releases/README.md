# Release history

Read the notes for each version to understand its changes, compatibility and
upgrade considerations. Candidate notes describe planned changes and do not
establish that the package is available on PyPI.

- [0.3.0](0.3.0.md): explicit updates for existing books.
- [0.2.0](0.2.0.md): optional contributor retrospectives.

Release preparation requirements are in [the agent instructions](../../AGENTS.md#pypi-releases).
