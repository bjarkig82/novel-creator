# Novel Creator 0.4.0 candidate

This is an unpublished release candidate. Windows Codex Desktop notebook
acceptance is pending; structural tests alone do not establish writing behavior.
See the [release evidence](../../tests/evaluations/agent-story-notebook-release.md).

The candidate adds a native Codex Markdown story notebook for new novels,
with native Codex notebook guidance and English or Icelandic localized seed
content. Writers can request a topic brief; the workflow does not call for
an automatic recap. Python is used for setup, not as a per-turn writing runtime.

The notebook is for new novels only. It does not migrate existing novels.
Existing novels retain their legacy commands and pinned workflow; installing a
new package does not itself update a book. The existing-book updater and other
legacy behavior remain available.

Newly initialized candidate notebooks also include stage-aware brainstorming and
optional book-idea, premise, character, plot and setting skills. With no concept,
guidance starts broadly with the writer's interests and asks one question at a
time. Explicit topics or methods take priority, including mind mapping before a
subject is known. The outline skill remains explicit-only. These instructions
keep proposals and open questions distinct from accepted story facts and create
no manuscripts. Existing notebooks do not acquire the additions automatically.
See [functionality](../functionality.md) and [conversation evaluation scenarios](../../tests/evaluations/brainstorming.md)
for behavior and evidence limits. The published legacy release does not supply
these notebook additions; this candidate has not been published.
