# Novel Creator 0.3.0

This release adds explicit updates for existing 0.1.0 and 0.2.0 books. Install an
external controller with `python -m pip install --upgrade novel-creator==0.3.0`
after publication, then follow the [update guide](../../workflows/getting-started.md#updating-an-existing-book).
Installing the package alone leaves pinned book resources unchanged.

The workflow checks published stable releases only when asked, previews an exact
release and book checkpoint, and requires explicit application. Updates preserve
story records, manuscript, custom instructions, unrelated staging and retrospective
permissions. A dedicated framework commit and local operation evidence support
interruption recovery. Successive updates support unchanged launchers; affected
shared files with local edits are refused; completed recovery inspection remains
complete after subsequent writer commits.

Close legacy clients through initial application and recovery (FUP-001). Keep
Windows preview/apply/recovery in the same access context; intermittent runtime
fingerprint changes remain a conservative refusal, never an authorization to
bypass checks. Direct native-user update input and Linux Codex integration remain
unverified. Windows host evidence uses the explicitly approved delegated scope.

Publication uses the existing protected workflow's exact verified candidate
wheel and sdist without rebuilding. Candidate and public archive identities,
platform checks and evidence limits are recorded in the
[release evaluation](../../tests/evaluations/existing-book-update-release.md).
