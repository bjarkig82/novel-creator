# Novel Creator 0.2.0

Newly initialized novels include optional automatic contributor retrospectives.
Participation is disabled for everyone until an explicit, novel-specific opt-in.
Contributors configure a separate framework checkout and use existing GitHub
authentication. A supported finding may produce a focused, tested draft PR;
merging remains a human decision. Routine replies and speculative features do not
start contributions. Privacy review, revocation, validation, preserved writing
work and interruption-safe recovery remain required.

Install with `python -m pip install --upgrade novel-creator==0.2.0`, then initialize
a new novel with `novel-creator init "My Novel"`. Upgrading the package does not
upgrade an existing novel's pinned code or workflows. Existing-bundle upgrades
remain deferred.

Read the [getting-started guide](../../workflows/getting-started.md) and
[contributor workflow](../../workflows/retrospective.md) before enabling contributions.

Windows Codex native qualification and the controlled real publication test have
distinct, recorded scopes. Linux installation/CLI verification is separate from
Linux Codex integration, which remains unverified. Earlier failed and partial
acceptance attempts retain their results. No universal host, semantic privacy,
literary-quality or performance guarantee is made. See the
[qualification matrix](../../tests/evaluations/automatic-retrospectives-qualification.md).

Release verification and immutable archive identities are recorded separately in
the [release evaluation](../../tests/evaluations/automatic-retrospectives-release.md).
