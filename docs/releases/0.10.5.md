# Novel Creator 0.10.5

**Published on PyPI on 2026-11-20**, compared with [0.10.4](0.10.4.md).
[PyPI distributions](https://pypi.org/project/novel-creator/0.10.5/#files)

## Changes since 0.10.4

- An explicit issue retrospective can freeze a partial ZIP of a writer-selected
  recording debug session with `retro issue begin --keep-debugging --input FILE`.
  The input selects the session by UUID and uses `"trigger":"explicit"`. The
  session continues recording, and later events stay outside the frozen export.
  An identical request reuses the existing run and ZIP. Stopping before export
  remains the default and is required at session closure.
- The first reply to a local retrospective identifies each evidence-supported
  GitHub issue candidate, explains why it merits filing and gives its status or
  next action. It says when there are no new candidates and reports publication
  status. Local review can happen before there is a formal run or issue draft.
  Sharing an issue or its attachments still requires approval of the exact
  outgoing material.

The updated retrospective workflow and skill cover both legacy novels and
format-1 notebooks. Windows and Linux support Python 3.11+ and Git 2.39+.
Native skill discovery and reload, live voice behavior and actual assistant
replies in the host require direct observation.

## Install or upgrade

Run this command in a Python environment outside the novel.

```text
python -m pip install --upgrade novel-creator==0.10.5
```

New projects receive the resources during normal initialization. Existing legacy
novels use the external controller's reviewed framework update to 0.10.5, which
creates a dedicated framework commit. Existing notebooks use the reviewed
`retro issue setup` to refresh the four linked guides, the managed retrospective
routing in their root instructions and the project-local retrospective skill
where installed. For plugin notebooks, also update and enable the matching
plugin. Notebook setup makes no story save or Git checkpoint. Installing the
package alone leaves project-local resources pinned.

Use the complete preview, apply and host reload steps for your project format.
[Project upgrade instructions](../upgrading-projects.md#live-debug-snapshots-and-local-retrospectives-in-0105)
