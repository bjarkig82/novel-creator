# Novel Creator 0.10.6

**Unpublished candidate**, compared with [0.10.5](0.10.5.md).

## Changes since 0.10.5

- In both novel formats, a retrospective checks up to 100 open and closed public
  issues before suggesting a filing. A confirmed equivalent gets a link.
  An incomplete comparison leaves the finding pending. Local-only review skips
  GitHub reads. When the GitHub CLI cannot read or authenticate, a host GitHub
  connector can compare issues and pull requests and submit an exactly approved
  issue. The workflow records the creation intent and can reconcile an uncertain
  result from a matching GitHub issue receipt. [Retrospective workflow](../../workflows/retrospective.md)
- Format-1 notebook recaps, including spoken continuations, preserve the scope
  and timing of supervision. For example, supervising a student's work at a
  company leaves the identity of their academic supervisor open. [Notebook conversation workflow](../../notebook/workflows/conversation.md)
- A notebook writer can explicitly assign a specialist authority to review,
  select and save proposed additions to a specified existing character profile.
  An ordinary drafting assignment keeps additions in chat for the writer's
  approval. [Character development](../character-development.md#assign-a-specialist-a-proposal-save)
- Notebook issue-setup previews show each conflicting managed workflow's path
  and the replacement rendered for that book. Writers can compare their edits
  before applying the update. [Review workflow conflicts](../upgrading-projects.md#review-workflow-conflicts)
- Run `novel-creator notebook check-index --path BOOK` to compare counts in the
  working summary with the linked topic notes. It reports mismatches and
  unavailable comparisons without editing files. A summary with no count rows
  reports zero checked. [Supported tables and exit codes](../functionality.md#check-topic-index-counts-on-demand)

## Install or upgrade

After publication, install the package in an environment outside the novel.

```text
python -m pip install --upgrade novel-creator==0.10.6
```

New projects receive format-specific guidance at initialization. Existing legacy
novels use the external controller's reviewed framework update. Existing
notebooks first apply reviewed issue setup, then merge the remaining character
guidance from a matching disposable reference. Plugin notebooks also need the
matching enabled plugin. Reopen the book and reload the instructions and skills
in the actual host. The read-only index checker works on existing notebooks
immediately after installing the package. [Complete project upgrade steps](../upgrading-projects.md#upgrade-to-0106)

The recap and delegated character guidance and the index checker apply to
format-1 notebooks. Legacy novels continue to use their existing writing
workflows. [Legacy writing guide](../../workflows/everyday-writing.md)
