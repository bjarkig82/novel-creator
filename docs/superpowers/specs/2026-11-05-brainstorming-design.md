# Stage-aware notebook brainstorming

Approved scope: make ordinary notebook conversation discover a book idea before
asking for detailed characters, plot or outlines when no concept exists. Detect
a useful starting point from actual project/topic notes and the current request.
An explicit topic or method takes priority and persists while relevant; writers
can switch naturally. Unknown genre is allowed, not a questionnaire to complete.

Use one shared, platform-independent brainstorming workflow and thin focused
Codex skills for book-idea discovery, premise, character, plot and setting. Ask
one useful question at a time, follow answers and keep suggestions optional.
Methods include associations, conversational freewriting, mind mapping,
perspective changes and focused questions, adapted to the current stage. Automatically select and adapt the method as well as the focus from actual
context and replies when there is no explicit method choice. A
writer can choose a method before knowing their book's topic. Outline remains
explicit-only. Preserve language, writer authority, provisional choices, open
questions, automatic notes and manuscript boundaries.

Resources ship and initialize in new format-1 notebooks in English or Icelandic.
No runtime internet dependency, conversion, automatic notebook upgrade, legacy
capture redesign, package version change or package publication. The user
authorized committing and pushing the completed, reviewed changes to main.

## Source basis

- [UNC Writing Center: Brainstorming](https://writingcenter.unc.edu/tips-and-tools/brainstorming/)
  describes freewriting, listing associations, clustering/mapping, perspective
  changes and journalistic questions. These are general writing techniques;
  conversational fiction adaptations here are design choices, not claims of
  proven literary effectiveness.
- [Randy Ingermanson: Snowflake Method](https://www.advancedfictionwriting.com/articles/snowflake-method/)
  assumes prior brainstorming and moves from a one-sentence premise through a
  paragraph toward detail. Use as an optional later expansion, never an empty-book
  default or required plot structure. Sources were checked during design; the
  installed workflow contains the guidance and requires no browsing.
