# Character development

First read and follow [project routing](../../references/notebook.md). Establish
the selected `novel_path`; the plugin cache is never a book.
Read and follow `<novel_path>/.novel-notebook/workflows/character-development.md`
and the selected book's role, conversation and format snapshots.
Offer one numbered batch of actual proposed profile prose, keeping drafts and
all revisions entirely in chat until explicit approval to save current or
selected additions. This exception overrides automatic notes, summaries, handoffs
and checkpoints in every role and language. Do not offer another batch unless
requested. Preserve canon, identity, ownership and history on approved saves.
Ordinary question-led character exploration and Clarify remain separate methods.
Use the active host's native file and Git tools and respect host permissions.
If the pinned workflow or supported notebook is unavailable, explain the limit
and preserve files; do not substitute a legacy workflow or convert the book.
