# Chapter writing

First read and follow [project routing](../../references/notebook.md). Establish
the selected `novel_path`; all snapshot paths below are relative to
`<novel_path>/.novel-notebook/workflows/`, never this cached skill.

Read and follow the shared `manuscript.md` snapshot (manuscript workflow)
and `agents.md` snapshot (role and handoff rules).
 Apply chapter and scene guidance to the requested material. Preserve current prose history and single ownership when incorporating scenes; do not delegate a separate agent for every scene by default.
Use the active host's native file and Git tools and respect host permissions. A skill
provides a method; it does not prove a native specialist switch occurred.
If the workflow or format-1 notebook is unavailable, explain the limitation and
preserve existing files; do not substitute legacy capture or convert the book.
