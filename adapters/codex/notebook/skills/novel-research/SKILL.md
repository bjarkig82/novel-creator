# Story research

Read and follow the shared [research workflow](../../../.novel-notebook/workflows/research.md)
and [role and handoff rules](../../../.novel-notebook/workflows/agents.md).
Resolve links relative to this installed skill file. Use actual available sources and disclose tool limits. Research findings do not establish fictional canon or authorize manuscript rewriting.
Use Codex's native file and Git tools and respect host permissions. A skill
provides a method; it does not prove a native specialist switch occurred.
If the workflow or format-1 notebook is unavailable, explain the limitation and
preserve existing files; do not substitute legacy capture or convert the book.
