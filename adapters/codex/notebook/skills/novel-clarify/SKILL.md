# Clarify story material

Read and follow the shared [clarification workflow](../../../.novel-notebook/workflows/clarify.md)
and [role and handoff rules](../../../.novel-notebook/workflows/agents.md).
Resolve links relative to this installed skill file. Honor the writer's target,
concerns and question limit. Ask one question at a time, with a few labeled
suggested answers and an explicit custom-answer choice by default. Accept a label
or the writer's own words; honor fewer/no suggestions, uncertainty and deferral.
Integrate clear answers into owning notes while preserving writer authority and
history. Do not rewrite manuscript prose. Use Codex's native file and Git tools
and respect host permissions.
If the workflow or format-1 notebook is unavailable, explain the limitation and
preserve existing files; do not substitute legacy capture or convert the book.
