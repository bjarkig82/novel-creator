# Resume and inspect

Read fresh `context --view working` and `session list` using the installed local
launcher. Follow [working-context.md](working-context.md) for targeted records and
exact sources; a compact session summary is navigation, not the complete session.
List stable session IDs, topic, mode and open/closed state. Duplicate names do
not merge sessions. Select the requested ID; ask a focused selection question
only when ambiguity remains. Restore saved mode, focus, decisions, canon, ideas
and relevant open questions without asking the writer to retell recorded information.
An explicit request is required to reopen a closed session; preserve its ID and
started_exchange_id. Session changes are typed revisions in the next conversation.

Expose last_saved_response with display marked unconfirmed. Offer its exact
saved text when recovering after interruption; never infer it was seen, agreed
with or accepted. Save any new conversation before showing its prepared reply.

Use `inspect --kind KIND --id ID --revision N` to retrieve current or historical
versions and sources. Derived summaries cite record revisions and checkpoint
and cannot override authoritative versions, omit unresolved conflicts or
conceal incomplete coverage. Missing/damaged/unsupported records are unavailable,
never empty context. Explain only recorded connections with sources. New
foreshadowing or motivation opportunities remain non-blocking proposals.

Do not give an unsolicited recap. When a summary is requested, retrieve its full
requested scope, using `--view current` or inspect where needed. In the visible
saved summary cite the supporting record IDs and revisions plus
the checkpoint for established facts, proposal/question groups and findings.
Session ID and checkpoint alone do not identify which record versions support
those claims. A compact reference list is sufficient; use full IDs or unambiguous
prefixes from the recovered state. Include all saved open questions, including
preference questions, within that requested scope, without treating them as newly asked questions or adding
new creative exploration when a checkpoint pause applies.
