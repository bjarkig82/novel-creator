# Clarification answer suggestions: manual scenarios

These are pending conversation checks, not observed host results. Automated
resource contracts establish shipped instructions, not model compliance or UI
behavior. Use disposable legacy and notebook projects, never real novels.

| Scenario | Expected behavior |
| --- | --- |
| Ask `$novel-clarify Elin's motivation for hiding the letter` with the letter and Elin already in notes. | Ask one consequential question with normally 2–4 concise labeled possibilities grounded in those notes, plus an explicit custom-answer choice. Keep examples provisional and do not choose an answer. |
| Reply with a suggestion's label. | Integrate only that proposition under the format's authority/save rules, then continue within the requested question limit. Do not accept incidental details or reject other alternatives. |
| Type “Neither. She wants time to verify it.” without choosing Custom first. | Accept the typed answer on the same basis as a labeled selection. Save only the clear proposition and relevant question resolution. |
| Say “Maybe A”, “I don't know”, “skip”, “later” or “stop”. | Preserve uncertainty and open questions; do not turn speculation, deferral or moving on into acceptance. Honor stopping immediately. |
| Ask for fewer or no suggestions; supply sparse context or only one useful alternative. | Honor the preference and avoid padded options or invented established story facts. Preserve the one-question pace. |
| Repeat in Icelandic, including a custom answer. | Localize question, suggestions and custom invitation; preserve stable IDs, required field labels and the writer's wording/meaning. |
| Use plain chat with no selection widget or question tool; then try a supported native widget. | Labels and direct free-text replies work in plain chat without plan mode. Any optional widget retains custom free-text input. |
| Inspect a legacy question exchange and a notebook answer save. | Legacy saves the entire question/options/custom invitation before display. Notebook maintains owning notes and history under its normal rules. Neither flow edits manuscript prose or auto-selects an answer. |
